# Skills for Claude Code (free)

🇪🇸 [Leer en español](README.md)

Skills that teach Claude Code to work methodically where a mistake is costly.

**Free and open source (MIT).** Use it in your projects and your clients' projects. The files are commented in Spanish.

## What's included

- `tdd`: real red-green-refactor cycles
- `changelog-release`: Keep a Changelog + SemVer, never publishing anything without permission
- `accesibilidad-web`: WCAG 2.2 AA checklist
- `instalar.sh`: installs them without overwriting anything

## Installation

```bash
git clone https://github.com/carlosp5751258-lgtm/ctrlia-skills-claude-code.git
bash ctrlia-skills-claude-code/instalar.sh            # or --global for all your projects
```

Restart Claude Code and ask, for example: “do it with TDD”.
