# Skills para Claude Code en español (gratis)

Skills que le enseñan a Claude Code a trabajar con método donde un error cuesta caro.

**Gratis y de código abierto (MIT).** Úsalo en tus proyectos y en los de tus clientes.

## Qué incluye

- `tdd`: ciclos rojo-verde-refactor reales
- `changelog-release`: Keep a Changelog + SemVer, sin publicar nada sin permiso
- `accesibilidad-web`: checklist WCAG 2.2 AA
- `instalar.sh`: las instala sin sobrescribir nada

## Instalación

```bash
git clone https://github.com/carlosp5751258-lgtm/ctrlia-skills-claude-code.git
bash ctrlia-skills-claude-code/instalar.sh            # o --global para todos tus proyectos
```

Reinicia Claude Code y pide, por ejemplo: «hazlo con TDD».
